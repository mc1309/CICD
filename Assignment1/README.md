# AndroidProgrammingQuiz-CrossPlatformCI

This repository contains a cross-platform OpenGL ES/WebGL application developed using a shared rendering architecture across **Desktop (Windows)**, **Android**, and **Web (Emscripten)**. The project demonstrates the use of a **Model + Renderer** design pattern, allowing multiple renderable objects to share the same rendering pipeline while keeping platform-specific code to a minimum.

The application renders a rotating coloured triangle alongside a yellow square using modern **OpenGL ES 3.0** rendering techniques. A reusable **ShaderHelper** class is used to load, compile, and link external GLSL shader files, making shader management consistent across all supported platforms. By sharing the same rendering logic across Desktop, Android, and Web, the project demonstrates code reusability, maintainability, and platform independence.

---

# Build Instructions

This project supports three build targets. Follow the instructions below to build and run the application on your preferred platform.

## 1. Desktop (Windows)

The Desktop version uses **CMake** to build the shared `Scene/` source files together with **GLFW** and **GLEW** for window creation and OpenGL functionality.

### Prerequisites

- CMake 3.15 or newer
- Visual Studio 2022 (recommended) or another C++17 compatible compiler

### Build & Run

The easiest method is to execute the provided build script from the project root:

```cmd
script_build_and_run.bat
```

Alternatively, build manually using CMake:

```sh
mkdir build_desktop
cd build_desktop
cmake ..
cmake --build . --config Debug
```

After the build completes, run the generated executable located inside the `build_desktop/Debug/` directory (or the equivalent output directory generated by your compiler).

---

## 2. Web (WebAssembly / WebGL)

The Web version uses **Emscripten** to compile the shared C++ source code into **WebAssembly**, allowing the application to run directly inside modern web browsers using **WebGL 2.0**.

### Prerequisites

- Emscripten SDK (`emsdk`) installed and activated
- Python 3 (used to host the generated webpage locally)

### Build & Run

Run the appropriate build script from the project root.

### Windows

```cmd
build_web.bat
```

### Linux / macOS

```sh
./build_web.sh
```

The generated webpage will be created inside the `web/` directory.

To launch the application locally:

```sh
cd web
python -m http.server 8080
```

Open the following address in your web browser:

```text
http://localhost:8080/
```

The browser should display both the rotating triangle and the yellow square using the same shared rendering system as the Desktop and Android versions.

---

## 3. Android

The Android version uses **Android Studio**, **Gradle**, the **Android NDK**, and **JNI** to compile and deploy the native C++ renderer onto an Android device or emulator.

### Prerequisites

- Android Studio
- Android SDK
- Android NDK (installed through the Android SDK Manager)

### Build & Run

1. Open **Android Studio**.
2. Select **Open** and choose the project's `android/` directory.
3. Allow Gradle to finish syncing the project.
4. Connect an Android device or start an Android emulator.
5. Click **Run** to build, install, and launch the application.

Alternatively, build from the command line:

```sh
cd android
./gradlew assembleDebug
```

Once installed, launch the application on the device or emulator to verify that both the rotating triangle and yellow square are rendered correctly.

# Expected Output

A successful build on all three platforms should display:

- A rotating coloured triangle
- A yellow square rendered alongside the triangle
- Both objects rendered simultaneously using the shared **Renderer** architecture
- GLSL shaders loaded from external shader files through the reusable **ShaderHelper**
- Consistent rendering behaviour across Desktop, Android, and Web while sharing the same C++ rendering codebase

This project demonstrates how a reusable rendering architecture can minimise platform-specific code while maintaining consistent functionality across multiple operating systems and graphics environments.
